JavaScript Calculator 🧮

A simple and responsive calculator built using HTML, CSS, and JavaScript. This project provides an interactive interface for performing basic mathematical calculations.

✨ Features

- Addition, subtraction, multiplication, and division
- Percentage calculations
- Clear and delete functionality
- Positive/negative number toggle
- Responsive calculator layout
- Interactive buttons with hover effects
- Error handling for invalid calculations

🛠️ Technologies Used

- HTML5 – Structure of the calculator
- CSS3 – Styling, layout, and visual effects
- JavaScript – Calculation logic and button interactions

📂 Project Structure

JavaScript-Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
 

🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start performing calculations.

No additional libraries or installations are required.

🎯 Purpose

This project was created to practise JavaScript fundamentals, DOM manipulation, event handling, and basic frontend development.
